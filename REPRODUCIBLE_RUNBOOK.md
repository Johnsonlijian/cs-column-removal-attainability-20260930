# Reproducible runbook

From the repository root, install Python 3.11 or 3.12 and NumPy, SciPy and
Matplotlib. Run the eight commands in `README.md`. The exact gate writes the
frozen JSON output and the audit recomputes all retained treatment instances.

The public nonlinear control is distributed only as a frozen derived output
and figure. Its third-party raw source files and original OpenSeesPy adapter
are not redistributed; `data/public_source_manifest.json` records the source
paths, line locators and hashes used in the local control.

The complete all-removal batched sweep is O(HB) for a fixed capacity vector after shared band potentials and prefix/suffix caches are built; local-screen values and independent audit values are computed through separate paths.

Runs with `max_load_factor_reached` are censored at the configured ceiling; the public figure uses open markers and omits ratios when either paired run is censored.
